# Gordix Studio（社群改版）

> 🚧 **完善中**：這是 [pfsin555/Gordix-studio](https://github.com/pfsin555/Gordix-studio) 的社群改版（貢獻者：小勝fink），功能仍在調整與實機測試。加工前請先用預覽確認路徑。原廠正式版：<https://pfsin555.github.io/Gordix-studio/>

線上試用：<https://fink1217.github.io/Gordix-studio/>

## 這個改版做了什麼

- **首頁**：改成依加工流程排列的 5 個步驟，下載 table.cfg 才算工作台已設定。
- **工作台**：加入尺寸比例校正精靈；鬆緊修正（機器多放出的皮帶長度，樣機實測 17 mm），table.cfg 自動扣除、對角線依同角度重算；超過機器上限時明確提示。
- **毛胚設定**（新步驟）：選板材尺寸（4×8 / 3×6 / 2×4 / 自訂）、厚度、材質與位置（置中或量測），各轉檔工具共用；超出加工範圍的部分畫斜線。
- **材質建議參數**：依毛胚材質與加工面板選的刀具，自動帶入走速、每刀深度（夾板採實測上限 2 mm）、雷射功率與速度；參數指南與各工具共用同一份資料。
- **CNC 加工（重寫）**：圖層決定加工方式（依圖層名或顏色自動分組）、刀具庫（依毛胚材質帶入走速與每層下刀）、同一把刀同一檔／換刀分檔並附換刀步驟、檔內由機器中心往外；2D 工作台預覽（拖曳擺放、實際刀寬、加工順序、機器底面）與 3D 切削模擬、刀路動畫。單一刀具時輸出與舊版逐行相同。V 雕刻與沿線雕刻（演算法原樣搬自舊 V 雕刻頁、結果相同）；放樣檔（外框、孔位十字、零件編號，畫筆或雷射）、只標孔位（手鑽）；中央高精度區標示。外框和它包住的孔、槽自動成為一個群組（點一下整組移動，雙擊選單一物件，Ctrl+G／Ctrl+Shift+G 群組／解散）；Ctrl+Z／Ctrl+Y 復原重做（繪圖工具也有）。
- **繪圖工具**
  - 支援一次匯入或連續追加多張 SVG、DXF、點陣圖；每張圖保留自己的圖層與畫法。
  - 物件清單勾選或 Shift 點擊多選，可群組／解散、整體移動與等比例縮放。
  - 輸入角度或拖曳圓形把手旋轉，Shift 拖曳每 15° 吸附；預覽、SVG 與 G-code 同步，支援復原／重做。
  - 點陣圖自動分成「細線」（畫中線）與「色塊」（畫外框／填滿）。
  - 圖層面板：可勾選、選畫法、調順序；點預覽上的圖形可移到別的圖層。
  - SVG／DXF 依圖層名或顏色分組，外框保留原向量，太細的封閉圖形改畫中線。
  - G-code 預覽 2D／3D 切換、進度滑桿，可從機器面板顯示的百分比產生續畫檔。
- **數字欄位可輸入算式**：例如 `2440/2`、`2702-17`、`(1220-40)*2`，按 Enter 或離開欄位就換成結果。
- **G-code 編輯器**：加入 2D（正上方俯視）／3D 切換；切削模擬（3D 看到板材被平刀／球刀／V 刀切掉、切穿成洞）與刀路動畫（播放、倍速、拖進度、剩餘時間）。
- **繪圖工具**：G-code 預覽可播放動畫。

## 使用

純 HTML／JavaScript，不需要安裝或編譯。直接開線上版，或在專案資料夾執行：

```
python -m http.server 8765
```

再用瀏覽器開 <http://127.0.0.1:8765/>。

## 開發驗證

幾何轉換測試：`node tests/objects.cjs`。

啟動上述本機伺服器後，安裝 Python Playwright 與 Chromium，執行 `python tests/draw_objects.py`，驗證多圖、群組、旋轉、復原、灰階功率與匯出座標。測試只在獨立瀏覽器執行，不操作實體機器。
