# CNC 專案與既有刀路恢復

左側「儲存專案」下載 `.gordix.json`，包含完整原圖、物件座標、群組、圖層、刀具、加工與工作台毛胚設定。「開啟專案」可恢復繼續編輯。工作台與毛胚以存檔內資料載入，不改寫其他頁面儲存的校準設定。

修改後會使用 IndexedDB 自動備份，完成時間顯示在專案區。重新載入時按「恢復上次工作」。瀏覽器資料被清除或使用不同網站網址時，應以下載的專案檔恢復。

「匯入 G-code 預覽」可一次選多個檔案，在獨立視窗切換、播放或俯視既有刀路，不會重新排版或改動正在編輯的專案。預覽目前要求 G21、G90，支援 XY 平面的 G0/G1/G2/G3；不支援的 G 指令會拒絕，避免顯示錯誤座標。

既有 G-code 可透過預覽中的「儲存刀路恢復檔」保存，再以「開啟專案」開啟。這是 `gordix-gcode-recovery` 格式的唯讀刀路檔，與可繼續編輯的 `gordix-cnc-project` 格式不同。G-code 沒有原始圖層、群組、轉換矩陣等完整資訊，不能宣稱已精確找回原始 CAM 設定。

若同時有原始向量圖，可將向量線段與 G-code 對位，建立真正可編輯的 `gordix-cnc-project` 專案。這類反推專案可附 `job.recovery` 的原刀路與加工設定指紋：設定未變時直接保留原始輸出，單獨調整橋位時沿用原輪廓分段與橋位範圍，只改 Z。隱藏預覽、重新命名及物件群組不會讓原刀路重算。位置、刀具、深度或其他加工設定變動後，介面明示改用重新計算的 CAM。這不代表找回原始專案中未記錄在 G-code 的校準與編輯歷程。

舊 `gordix-gcode-recovery` 檔以「開啟專案／恢復編輯」匯入時，現在會嘗試升級成可編輯專案，不會直接導向預覽。支援附有 SVG、每件原圖包含外輪廓／挖槽兩個閉合輪廓與開放雷射線、以及雷射與平刀兩份 G-code 的封存檔。先以雷射線對位，再核對重算刀路的加工階段、深度、走速與雙向 XY 幾何（20 微米距離容差）。不能核對或缺少原圖時會拒絕，保留目前工作。成功時自動關閉預覽視窗；已在預覽中的舊檔也可按「恢復到主編輯區」。

`tools/repair_existing_tabs.py` 專供修復舊版末刀才保留橋位的輸出。它沿用末刀已有橋位，只處理低於橋頂的前置刀次；原輪廓指令必須逐一吻合，新增分段須在原始座標精度內共線，走速必須相同。不符合即拒絕。輸出只能另存於本專案內，不覆寫來源；同時產生雜湊與幾何誤差核對報告。這是離線檔案核對，不代表實機加工驗證。
