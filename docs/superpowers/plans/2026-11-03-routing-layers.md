# 刀路空跑優化與繪圖式圖層

目標：縮短不必要的空跑，讓圖層內的物件可辨識、可隱藏、可直接搬移。以電腦版為主，保留固定中央預覽。

設計決策：
- 加工幾何、切削方向、深度、層數、功率與換刀分檔不改。
- 使用者明確補充：只有雷射畫線不影響板面平整，可以自由排序。銑削與雷射切割完整保留既有中心往外順序；畫線仍在切割之前。
- 依上一刀終點就近選下一個可加工單元，封閉輪廓可平移起點但不反轉；開放雷射線可反向，銑削方向不反轉。有限次局部改善，並比較原序列，避免可行原序列反而變差。
- 介面提供「減少空跑」與「由中心往外（原方式）」；顯示依實際G0計算的空跑距離，不宣稱數學上的全域最短。
- 圖層標題有合成縮圖，展開後每個物件有縮圖、名稱、隱藏眼睛、輸出勾選、移至圖層選單及拖曳搬移。群組概念與原本畫布選取保留。
- 眼睛只控制編輯畫面的顯示，輸出勾選控制加工內容；隱藏不會偷偷刪掉輸出。所有可變資料沿用既有復原快照。

檔案：gordix-route.js負責純排序；gordix-cam.js建立加工先後限制、比較實際G0距離；CNC.html負責圖層與排序控制；gordix-ui.css負責圖層布局。

範圍修正：依使用者補充，移除一般銑削的自由排序與新依賴圖，避免改到原本維持板面平整的加工策略。測試追加銑削G-code在切換畫線排序模式後逐行不變。

追加橋位需求與驗證：舊程式只在最後一層抬高橋位，18 mm 板＋過切0.3＋每層2 mm 時，前一層已切到 Z-18，破壞最後一層要保留的材料。改為依板厚與 tabHeight 計算 tabTopZ，所有更深的輪廓層都套用。新增厚度欄位、2D及3D標記與毛胚模型獨立顯示；模型保留完整毛胚範圍，切削區域使用實際G-code高度圖。

獨立審查修正：不輸出的物件／圖層必須從材料內外判定排除，避免錯側刀徑補償；眼睛隱藏不影響加工內外判定。已新增先失敗再通過的回歸。

追加空切加速：依使用者明確要求保留加速，增加獨立G0 F輸出及開關，預設2000 mm/min（沿用專案既有軟體上限），回G1強制恢復加工F，不變更韌體加速度。實機G0是否採用F尚未驗證；提示明確說明。
