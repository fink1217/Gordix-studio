# 多圖物件、群組與旋轉實作計畫

目標：追加匯入多張 SVG、DXF 與點陣圖，每張圖保留可編輯的圖層；選取多張圖建立或解散群組，整體移動、縮放與旋轉。

架構：使用物件陣列保存各自的原始來源、分析結果、圖層、轉換與預覽。既有區域分析器繼續編輯作用中物件，群組僅保存成員關係。共用座標轉換同時供預覽、外框與匯出使用，角度為逆時針正值。

技術：原生 HTML / JavaScript，沿用 Python Playwright 測試工具；不新增執行期相依。

- [x] 改為逐檔序列匯入並保留既有物件；載入失敗不破壞先前物件；相同檔案可重複加入。

- [x] 執行既有繪圖相關回歸測試，檢視桌面及手機截圖，更新離線快取。

風險：共用分析畫布不能被同時載入覆寫；因此序列處理，分析期間鎖定物件切換與匯出。快照保留來源參照、複製可變編輯狀態，避免每筆操作複製大量像素。既有單圖輸出保持座標精度與加工模式。

驗證重點：空圖／損壞檔、混合點陣與向量、隱藏所有作用中圖層仍能輸出其他圖、旋轉後超出加工範圍、群組解散後保持位置。

審查修正：歷史快照引用各次分析版本，還原門檻時同時還原幾何；輸出依最新全域功率上下限重新計算灰階功率。新增整合測試先確認兩項失敗，再修正至 27/27 通過。
