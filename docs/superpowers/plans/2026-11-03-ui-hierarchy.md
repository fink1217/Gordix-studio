# UI 視覺層級與流程排序

目標：改善整個站點的注意力分配、閱讀層級與加工步驟辨識。保留現有輸入、快捷鍵、進階開關、加工邏輯、檔案格式、設定儲存及預覽手勢。

範圍：首頁、工作台、毛胚、CNC、繪圖、G-code 檢查、參數指南、舊 V 雕刻。

設計決策：
- 以 A1 Gallery 與 Minimal Gallery 的節制留白、清楚字級和一致格線作視覺參考。
- 使用既有橘色品牌與中性石墨灰；降低大型漸層和每張面板爭搶注意力的色彩。警告、圖層顏色與加工範圍標記保持語意。
- 頁首加上輕量的流程位置導覽：工作台、毛胚、加工設定、檢查輸出；沿用既有頁面連結。
- 輸入數值最清楚，區塊標題其次，說明維持可讀但較安靜；焦點所在面板以細邊線提示。
- 主要下載按鈕優先，匯入為次級操作，模式切換和一般工具降低視覺重量。
- 繪圖右欄改為毛胚摘要、物件擺放、工具與走速、功率、輸出；保留左右欄分工，不搬動預覽。
- 所有頁面共用 CSS，雙主題與手機支援；不新增執行期依賴或遠端字型。

執行：
- [x] 記錄現有表單契約與桌面截圖，新增流程導覽／版面冒煙測試並確認失敗。
- [x] 共用視覺樣式與靜態導覽，逐頁設定面板層級；僅對繪圖右欄進行實際順序調整。
- [x] 桌面、平板、手機及雙主題視覺驗證；核對原有表單 ID、類型、min/max/step/accept 與互動。
- [x] 執行既有功能測試，檢查主要輸出不變；更新快取，獨立提交與推送。

驗證：本機 Playwright，保留前後截圖；不操作實體 CNC。參數、路徑計算及機器控制不是本次 UI 修改範圍。

載入驗證：外部 Tailwind CDN 在壓測時偶發未載入，改為網站附帶同一份 Tailwind 3.4.17 瀏覽器執行檔與 MIT 授權。避免樣式啟動依賴外部 CDN；未新增框架或變更加工流程。
