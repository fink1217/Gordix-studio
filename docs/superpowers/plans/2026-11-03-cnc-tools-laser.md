# CNC 自訂刀具與雷射畫線

目標：讓刀具可命名與直接修改規格，圖層增加獨立雷射畫線，並可設定每層功率百分比、走速與重複次數；實際G-code必須依這些數值輸出。

設計：沿用現有刀具庫與圖層資料。自訂刀具增加名稱、刃數輸入及明確編輯入口，仍以平刀／V刀／球刀幾何產生CAM，不新增不存在的刀具形狀。雷射畫線與切割共用雷射輸出，但畫線不視為材料邊界，不做刀具補償，開放路徑保持開放。每個雷射圖層獨立保存功率、走速、次數，材質建議由使用者明確套用。

- [x] 刀具增加名稱、直接刃數輸入、清楚的新增／編輯入口與保存驗證。
- [x] 驗證自訂刀具持久化、開放線不封閉、S值／F值／次數、圖層復原與其他加工結果；審查後推送。

追加需求：電腦版 CNC、繪圖、G-code 檢查固定中央預覽，功能欄獨立捲動；手機維持原本直向排列，專門優化留到最後。固定區域以 1024×720、1440×650 和實際刀路驗證。
